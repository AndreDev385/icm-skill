# Forms — the smallest structure that fits the work

## The one question

**What is the repeating unit of work?** Everything follows from the answer: one
bounded task, a sequence with review points, accumulating records, shared
knowledge, several workflows under one home, an organization, or a folder
later agents will change.
Design from one recent completed example — never from a wish list — and keep
what happens today separate from what is proposed.

## The catalog

| Form | When the repeating unit is… | Shape | Wrong when |
|---|---|---|---|
| **Saved prompt** | one bounded task, the same every time | one file: the instruction, its inputs, its check | the task has sequence or review boundaries |
| **Pipeline (numbered stages)** | a repeated sequence where people check between steps | `stages/NN_*/` contracts + a run folder per execution | there is no real gate between the steps |
| **Record library** | context accumulates per client / case / project | one folder per record + a shared factory | records never accumulate; everything is one-off |
| **Knowledge bundle** | the knowledge itself — a brain, a wiki, a system someone must understand and not run | `docs/`/`_shared/` + a reading contract (diagrams + an annotated reading order) | it hides work that belongs in stages |
| **Umbrella** | several workflows share one identity and one loop | root map + router + one workspace per workflow | one workflow split into many for symmetry |
| **Context map** | the subject is an organization — teams, processes, data, and the links between them | node cards + typed links + scoring frontmatter | it copies the org's docs instead of citing them |
| **System map** | a folder later agents will change (code, vault, or both) | `map/`: object + process cards + a change-impact index | work that needs gates is run through it |
| **Router** | the work is navigating an existing system | an index routing to the real homes | it becomes a second copy of those homes |

System map method (gated slices, cards, walk test): `system-map.md`.
Restructuring an existing tree into any of these forms: `restructure.md`.

## Rules

- **Say "a saved prompt is enough" when it is.** The smallest right structure
  beats an impressive wrong one.
- **Forms compose.** An umbrella of record libraries; a pipeline whose runs are
  record folders; a knowledge bundle inside a stage. Compose only when the
  repeating units genuinely differ.
- **One workspace = one mental mode.** If how you think changes between two
  kinds of task, those are two workspaces.
- **Start minimal** — map, one workspace, one or two references — and grow on
  evidence. Every agent mistake is a signal to add a doc, wire a skill, or
  clarify a contract.

## Worked shapes

- Umbrella of pipelines and record libraries: one root with a pipeline folder
  (one artifact per relationship) and a content folder (pipelines + production runs).
- Client umbrella of workspaces: one repo that holds several workspaces for a single client.
